# Salinometer

Handheld conductivity salinometer (Salinometer v2, Rev C) for the Science Olympiad Water Quality (Div C) event.

## Layout

| Path | Contents |
|------|----------|
| `docs/` | Design brief for building the schematic and PCB in EasyEDA via MCP (`salinometer_easyeda_prompt.md`) |
| `pcb/gerber/` | Gerber fabrication package (`Gerber_PCB1_2026-11-17.zip`) |
| `pcb/3d-model/` | 3D model export of the board (`3D_PCB1_2026-11-17.zip`) |
| `pcb/assembly/` | Assembly files: bill of materials (`BOM_Board1_PCB1_2026-11-17.xlsx`) and pick-and-place file (`PickAndPlace_PCB1_2026_11_17.xlsx`) |

Files are dated 2026-11-17 and named for board PCB1.
